# Travel Portal Demo

White-label travel companion app prototype using Vite, React, TypeScript, MSW, React Query, Tailwind CSS, and shadcn/ui.

## UI Stack

- Tailwind CSS v4 via `@tailwindcss/vite`
- shadcn/ui configuration in `components.json`
- Shared class utility in `src/lib/utils.ts`
- Component aliases use `@/components`, `@/components/ui`, and `@/lib`
